# Seal World 🦭

Projeto de estudo de **JavaScript Full Stack** — landing page sobre focas (seals), em inglês, feita como **Exercício 1 do Módulo 1**, no início da minha jornada de programação.

Código 100% autoral, escrito por mim na época sem auxílio de ferramentas — por isso os arquivos são mantidos exatamente como foram criados, sem refatoração.

## O que pratiquei neste exercício

- Vídeo de fundo no hero (`<video autoplay muted loop>` com `<source>`)
- Google Fonts (Oxygen) com `preconnect`
- Nomenclatura de classes no estilo BEM (`hero__title`, `section__img`, `gallery__img-wrapper`…)
- CSS: `object-fit`/`object-position`, `float` para imagem com texto ao lado, `transform: rotate()`, pseudo-elemento `::after` e seletores `:nth-child(even)`
- Galeria estilo "polaroid" com fita adesiva vermelha feita só com CSS

## Como visualizar

Basta abrir o `index.html` em qualquer navegador — não precisa de servidor nem instalação.

## Estrutura

```
index.html   # Página Seal World (hero com vídeo, seções sobre focas, galeria)
index.css   # Estilos da página
img/         # Fotos de focas (Pexels)
video/       # Vídeo de fundo 4K do hero (Pexels, ~21 MB)
```
